# 中西融合棋 (game_chess)

一个把中国象棋与国际象棋合并在同一棋盘上的休闲 H5 / 桌面棋类游戏示例。顶部为国际象棋阵营，底部为中国象棋阵营，双方按各自的走法行棋，吃掉对方王（将）即获胜。

## 特色

- **混合棋盘**：10×9 棋盘同时容纳两种棋子，布局兼顾双方特色。
- **双规则走法**：
  - 蓝方使用国际象棋的走法（兵仅向前一步，到底升变为后）。
  - 红方使用中国象棋的走法（兵过河后可横向移动，马象带“绊脚”规则，炮需隔子打子，将/士限于九宫）。
- **轻量易玩**：纯 HTML/CSS/JavaScript，无需依赖，适配桌面与移动端。

## 本地运行

1. 克隆或下载本仓库。
2. 使用任意静态服务器打开根目录（以下命令任选其一）：

   ```bash
   # Python
   python -m http.server 8000

   # 或者使用 Node.js
   npx serve . -p 8000
   ```

3. 浏览器访问 `http://localhost:8000`，点击棋子即可查看可落点并完成走棋，点击“重新开始”回到初始布局。
